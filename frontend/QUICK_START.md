## 🚀 Quick Start (After Node.js Upgrade)

### Option 1: Upgrade Node.js (Recommended)
1. Download Node.js 20.19+ or 22.12+ from https://nodejs.org/
2. Install and restart your terminal
3. Navigate to frontend folder and run:
```bash
npm run dev
```

### Option 2: Quick Fix (Downgrade Vite)
If you can't upgrade Node.js right now:
```bash
cd "C:\Users\aades\OneDrive\Desktop\New folder\TokeDex\frontend"
npm install vite@5.4.11 @vitejs/plugin-react@4.3.4 --save-dev
npm run dev
```
